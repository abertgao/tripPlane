# 山河行记 · 筛选范围随机探索需求

创建日期：2026-09-28；来源快照：`dec6bfb`；版本沿用 `0.1.0`。

## 用户诉求与输入

根据当前主题／地区随机挑选地点，滑块控制数量，确认后追加已有收藏，不替换原旅程。用户已授权实现及原网站热更新，并明确今后不经过 Cloud Studio，直接在现有本地单机发布。

## 目标与交互

路线页增加地区筛选及「让下一站，留点惊喜」路书卡，沿用纸色、深绿、衬线标题；主题、地区、搜索交集为唯一抽选范围。滑块默认最多3处，可选1至当前可追加数。先随机预览，支持换一组／收起，确认后一次性追加。

## 关键口径

- 已收藏、已跳过地点不进入随机候选；原选择顺序、跳过标记、任务答案、手记、日期、天数均不改。不能借随机跳过章节或标记到访。
- 全部主题／地区表示当前目录全部范围，不自动定位，不调用AI或地图服务。待核验地点可作候选，必须显示核验提醒；不是最优路线或实时开放推荐。
- 未确认不写存档；失败保留预览。筛选、数量、旅程、账号变化使旧预览失效；结束旅程需先重新翻开。
- 事务基于最新本机记录取并集，拒绝已被跳过或不属筛选范围的过期选择；重复确认不重复追加。游客本机可用，登录复用现有同步机制；本机成功不等于服务器同步成功。

## 验收标准

1. 地区、主题、关键词筛选与抽选结果一致；整数滑块、空池／单点／全部候选边界明确。
2. 无重复抽样；改变数量或筛选不能确认旧结果；预览、取消、换一组不写存档。
3. 确认仅追加且保留所有既有记录；并发新增记录、切号、切旅程、删除墓碑、容量限制和失败重试有保护。
4. 手机360–430px无横向溢出，按钮至少44–48px，滑块有标签及键盘支持，结果与保存状态可读。
5. 类型、Node回归、生产构建通过；浏览器若被系统沙箱阻断需如实记录，不关闭沙箱。
6. 发布只更新原站静态产物及公共SW缓存，不改API协议、不重启API、不清除私人存档、不提交Git。发布前确认权限、保留旧release及备份，切换后校验资源及健康；失败原子回退。

## 风险

随机多处不代表适合一天走完；地区不等于精确距离。现有 `updateState` 的函数补丁在事务外计算，本需求使用独立事务追加动作，不全面重构。现有运行环境历史上不能启动Chromium沙箱，应复核并记录实际结果。
