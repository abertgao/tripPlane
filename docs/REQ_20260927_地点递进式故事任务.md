# 地点递进式故事任务需求说明

- 日期：2026-09-27
- 对应计划：PLAN_20260927_地点递进式故事任务.md

## 用户原始诉求
当前“这一站，听什么故事？”任务清单不够深入。对每个地点按沉浸式开放世界RPG提示定制更新：疑问→调查→线索→新调查→完整故事；输入回答后才展开下一项。NPC须有动机和回应，任务具备因果关系、多样性、真实导航、合理游览范围和结局，不是景点打卡或学校问答。

## 输入
- shared/content.js 中25个地点与现有时间、兴趣主题、路线框架。
- 当前任务界面、个人旅程、旧版完成记录、同步/备份机制。

## 目标产出
- 每地点原创主线、最终目标、章节、路线/时间说明与3–5行动的QUEST。
- 逐项文字回答解锁与前置章节限制；线索回顾、个人结尾。
- 答案可保存同步、导入导出、恢复；旧勾选保留历史而非编造成答案。

## 关键口径
- 默认观察、环境叙事、轻解谜风格；不复制具体游戏IP。
- 真实地点、资料事实与虚构剧情区分，NPC反应不等于核验答案真假。
- 未提供具体游览时间和兴趣沿用现有地点预算与主题；不增加实时服务。
- 名称不明/入口待核验的地点显著说明，不编造地址、不指向同名异地、不诱导越界。
- 无法观察可如实记录未确认；不做知识标准答案评分。

## 验收标准
- 每个地点均有区别于其他地点的调查主线与明确收束。
- 同一地点内行动/章节逐步解锁，不可通过其他入口跳过。
- 空白不能提交；失败保留输入；刷新保持已提交答案。
- 旧存档、账号隔离、同步和AI已探索保护兼容。

## 风险与待确认
- 多个原地点仍待消歧，无法保证精准入口与开放；本次按核验优先的安全剧情处理，不宣称实地已核验。
- 全面重写内容须避免旧行动ID指向新含义。
- 不包含部署，不增加新的数据库或外部AI权限。
