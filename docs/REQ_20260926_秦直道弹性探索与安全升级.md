## 一、用户原始诉求（整理）

1. “读取这个需求背景，重新设计这个网页。”目标是给有深度历史、人文旅行经验的使用者设计沉浸式 RPG，而不是景点打卡或学校问答。
2. 用户最新明确“不局限于秦直道”：以本次自驾范围内的人文与自然探索为主题，秦直道仅为可选内容；能实际带着游览，采用真实背景中的明确标注虚构谜团，手机现场探索优先。
3. 交通为西安出发自驾；普通探索日步行约 2–4 公里；无已固定预订，允许删减和调整。
4. 希望保留自主 AI 接口，随时处理当日情况变化；首版先做完整接口与提案确认，不配置模型时明确不可用。
5. 供本人及少量同行者使用，各自独立存档；邀请制，不开放公众注册。
6. 允许复用现有服务器，优先申请免费公网 IP HTTPS 证书，不购买域名；具备 HTTPS 后启用账号与服务端同步。
7. 最新要求：9 月 27 日至 10 月 7 日，从候选地点中按心情选取，按顺路顺序组织；新增河套及阿拉善方向候选，不能继续锁定旧的包头终点。
8. “先规划后行动吧，规划文件也都存档到 docs 里。”尽量自主推进，可组织 agents teams，避免重复让用户做一般性决策。

## 五、验收标准

- 每一可执行任务有真实场所标识与导航，3–5 个现场动作、线索和后续动机；未核验场所不得启用任务导航。
- 可以临时跳过景点仍结束故事，明确“亲见”“资料了解”“未完成”，不把替代变成虚假到访。
- 同一条走廊支持至少两种不同选点组合，避免因固定剧情迫使用户折返。
- 未接入地图/天气/开放信息服务时不声称实时可达、今日正常营业或精确驾驶耗时。
- 用户 A 无法访问、列举、恢复、删除用户 B 的旅程和历史版本。
- 断网编辑不丢失；跨设备冲突可见，旧提案与删除操作不得静默覆盖。
- 旧 HTTP 和新 HTTPS 存档迁移有明确步骤；导入无自动覆盖，恶意导入被拒绝。
- 免费 IP 证书及续期实测成功才能称 HTTPS 交付；公网账号不降级到 HTTP。
