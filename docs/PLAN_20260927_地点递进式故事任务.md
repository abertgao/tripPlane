## 当前版本：网站现行版 / 递进任务升级
1. 这一版只解决：25个现有地点的定制故事、回答后逐行动与逐章节解锁、个人答案存档。
2. 满足什么就算完成：各地点具备主线、目标、范围/时间/路线约束、递进章节、每章3–5行动与结局；前端与服务端校验顺序，旧记录不丢失、不伪造新回答。
3. 当前必须修的阻断项：任意勾选/跳章、回答保存和同步、待消歧地点虚构导航风险。
4. 下一版再改的升级项：实时开放查询、自由生成世界、AI语义评分、实地自动定位。
5. 停止条件：新增问题不影响本版成立，不扩大重构或部署范围。

## 执行
1. 逐地点定制观察解谜型原创故事；已知真实地点与虚构NPC明确区分；未核验地点先核验，不输出假地址。
2. 建立统一进度校验和兼容迁移：旧勾选保留为历史，新答案按地点连续推进，保护既有探索。
3. 局部替换任务弹窗，展示主线概览、真实地点导航、答案回顾和依据答案的NPC回应，隐藏未解锁任务内容。
4. 完善内容、服务端、浏览器交互回归；不改部署、不提交git。

## 验收
- 全部地点有定制故事，历史事实依公开资料/现场说明，不替未知补答案。
- 空白、超长、未知行动、越级答案被拒绝；不同地点可独立开始。
- 旧旅程/导出/检查点可读，答案刷新不丢失、账号与旅程隔离。
- 阅读和输入无XSS、答案不发送AI、权限校验不削弱。
