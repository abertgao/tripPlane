# 用户的背景说明
一个对历史人文具有相当浓厚兴趣的人，对历史文物、建筑、艺术品等感兴趣，希望通过游览来了解历史。
硕士学历，有深度旅游需求和经历，懂的很多历史知识。使用者有历史地理教师资格证和导游证，喜欢的小说是鱼尾，马伯庸，希望后续任务故事有马伯庸的风格。喜欢玩的游戏是刺客信条和塞尔达。

# RPG形式的要求
对RPG形式的要求是，要符合RPG游戏的风格，要有故事线，具体prompt如下：
prompt:
请把我接下来要游览的古镇、小城市、历史街区、城堡、宫殿、故宫、博物馆园区等范围较明确的历史场所，设计成一场沉浸式开放世界 RPG冒险，风格参考（你喜欢的游戏）
核心目标
我不是来完成旅游打卡，而是要体验一个完整的故事从一个事件、人物、物品、传闻或谜团开始：
产生疑问 -调查-获得线索 -前往新地点 发现新线索 推进剧情 -最终形成完整故事
游览结束时，要让我感觉“我刚刚经历了一段故事”，而不是“我参观了几个景点”。
设计原则
1.强沉浸感
设置贯穿始终的主线剧情。NPC 是故事中的人物，不是导游或任务发布器；他们要有自己的动机，并根据玩家之前的行动和发现作出反应。
2.调查链
任务必须有因果关系。上一个任务获得的信息，要成为下一个任务的线索或行动动机。不要提前讲完历史，让玩家通过建筑、展品、艺术、老照片、街道和环境逐步拼出真相。
3. 景点服务于故事
不要设计成“城堡 教堂一博物馆”的景点清单。每个地点都必须对当前剧情有意义，同时抓住该地点最值得体验的核心内容。
4. 开放世界
允许自由观察和探索，但提供适度的任务引导。任务路线要符合真实地图，结合距离、开放时间、预约时间和实际游览时间，尽量顺路，不走回头路、不绕冤枉路。
5. 任务多样化
结合观察、摄影、博物馆调查、建筑细节、空间探索、历史人物视角、老照片对比、人物观察、当地生活体验、小型选择或挑战等。不要反复设计“寻找某个东西”。
6. 不要像学校作业
不要把任务写成“请分析/解释/回答为什么”。让玩家通过行动自然发现答案。
7.每个任务先给导航
每个 QUEST 开头必须提供：
9导航：“真实地点名称/地址"
必须可以直接复制到 Google Maps，不得虛构地点。

故事结尾
最终必须有明确人的剧情收束，让前面遇到的、地点、线索和历史知识在结尾串联起来，产生“原来这一切都是一个故事”的感觉。
如果地点范围很大，不要强行覆盖整座城市；选择一个合理区域或主题，做成一条完整的冒险故事。
